Putting it in Google Slides

Google Slides imports .pptx directly and keeps the layout, the charts and the speaker notes.

  1. Download ME344-final-5-slides.pptx.
  2. Open drive.google.com and drag the file in.
  3. Right-click it, then Open with, Google Slides.
  4. File, Save as Google Slides if you want a native copy rather than the imported one.
  5. Share, Anyone with the link if it needs to be public.

Speaker notes land in the notes pane, so View, Presenter view gives you the script while presenting.
